# বাজার দর (BazarDor)

BazarDor is a modern web application built to track daily market prices of essential goods[cite: 16]. Users can view current prices, check daily price changes, and filter products easily by category to make informed shopping choices.

## Technologies Used
* **Frontend:** Next.js, React, TypeScript, Tailwind CSS.
* **Authentication:** Better Auth (Email, Google, GitHub).
* **Database:** MongoDB Atlas.
* **Deployment:** Vercel.
* **Other Tools:** React Hot Toast.

## 5 Key Features
1. **Live Price Tracking:** View daily prices and percentage changes for essential market items.
2. **Category Navigation:** Easily find products using a smooth, highlighted category menu.
3. **Secure Authentication:** Log in and sign up safely using an email address, Google, or GitHub.
4. **Product Sorting:** Sort items quickly from highest to lowest price or lowest to highest.
5. **Responsive Design:** A clean, fast, and mobile-friendly user interface with instant success and error alerts.
